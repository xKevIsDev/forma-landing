# Forma Landing Page

A production-ready landing page for **Forma** — a design system platform built with React, TypeScript, Vite, and Tailwind CSS. Includes Stripe-powered pricing and a Supabase Edge Function for checkout sessions.

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Supabase (Edge Functions)
- Stripe

## Getting Started

```bash
npm install
npm run dev
```

Add a `.env` file with your Supabase credentials:

```
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```
